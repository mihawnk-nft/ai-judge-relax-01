Entry for [ai-judge-relax-01](https://make.fun/bounty/ai-judge-relax-01): a program
that writes one short text to `/output/entry.txt`, written to relax the AI judge
reading it.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
